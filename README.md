## Selected projects

### Assistant BCT — Bilingual document search

A French and Arabic assistant for exploring Central Bank of Tunisia circulars and notes, with answers linked to PDF sources.

- Combines semantic search in Qdrant with BM25 keyword search.
- Uses reciprocal rank fusion and a multilingual reranker to select relevant passages.
- Connects a FastAPI backend to a TypeScript interface and generates answers through Groq.
- Provides page references so users can check the original documents.

**Stack:** Python · FastAPI · Sentence Transformers · Qdrant · BM25 · TypeScript

The source repository is currently private. This is a demonstration project; it is not an official BCT service.
